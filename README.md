# MoneyLife

Личное приложение для учёта криптопортфеля: DCA 50/30/20, лестница докупок на просадках, план альткоинов, карточки монет.

- `index.html` — приложение (устанавливается на телефон: Safari → «Поделиться» → «На экран „Домой“», Chrome → «Добавить на главный экран»).
- Данные — в Supabase (таблица `docs`, доступ только владельцу), цены — CoinGecko.
- Код собирает и обновляет Claude.
