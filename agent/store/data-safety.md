# Google Play — раздел «Безопасность данных» (Data safety): что отвечать

*Подготовлено 12.11.2026 по коду приложения. Ответы — для формы в Play Console; сверять с privacy.html.*

## Собираемые данные (Data collected)

| Тип данных в форме | Что именно | Обязательно? | Зачем | Передаётся третьим лицам? |
|---|---|---|---|---|
| Личная информация → Адрес эл. почты | почта аккаунта | да | управление аккаунтом | нет (Supabase — обработчик) |
| Личная информация → Имя | только при входе через Google; имя для Ориона хранится на телефоне | нет | персонализация | нет |
| Финансовая информация → Другая финансовая информация | записи покупок/продаж, суммы, монеты | да (суть приложения) | функциональность приложения | **частично**: доли портфеля в % — в Anthropic (ответы Ориона, по желанию); округлённые суммы в тексте фраз — в ElevenLabs (живой голос, по желанию) |
| Аудио → Голосовые записи | **не собираем**: речь распознаёт система телефона, приложение получает только текст | — | — | — |
| Сообщения в приложении → Другое | текст вопросов Ориону и начало разговора | нет (по желанию) | функциональность (ответы) | да — Anthropic (обработчик), хранение до ~1 часа |
| Сведения о приложении → Журналы сбоев | только на телефоне; уходит письмом, если человек сам нажмёт «Сообщить об ошибке» | нет | отладка | нет |

## Практики безопасности
- Данные шифруются при передаче (HTTPS) — **да**.
- Можно запросить удаление — **да**: в приложении «Настройки» → «Аккаунт» → «Удалить аккаунт» и страница delete.html.
- Ключи сторонних сервисов (Anthropic, ElevenLabs) — только в секретах сервера, в приложение не попадают.

## Что сделать владельцу перед отправкой
1. Перенести таблицу в форму Play Console (раздел «Безопасность данных»).
2. В форме указать ссылку на политику: https://koshei96.github.io/moneylife/privacy.html (обновлена 12.11.2026, раздел «Голосовой помощник Орион»).
3. Если голос/«мозг» Ориона станут частью платной подписки — обновить таблицу (оплата через Google Play: Финансовая информация → История покупок).
