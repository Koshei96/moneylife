# Список задач агента

Агент берёт задачи сверху вниз (с учётом приоритета) и сам пополняет список.
Формат: `- [ ] P? — что сделать — почему/где видно`.

## От владельца

Пожелания владельца — всегда первыми. (Пока пусто. Владелец может написать Claude в чате,
и пожелание добавят сюда, или оставить комментарий в Pull Request агента.)
