# Озвучка ролика «MoneyLife за минуту» — тексты для ElevenLabs

Ролик уже работает без этих файлов: говорит живой голос Ориона (та же серверная функция, что у помощника),
а без интернета — голос телефона. Записанные файлы нужны, чтобы не тратить символы ElevenLabs на каждого
нового человека (~700 символов за просмотр) и чтобы звучало одинаково у всех.

## Как записать

1. ElevenLabs → Text to Speech. **Голос — тот же, что у Ориона** (тот, что стоит в функции `orion-voice`).
2. Модель: Eleven Multilingual v2 (русский и украинский одним голосом).
3. Настройки: Stability **55**, Similarity **75**, Style **10**, Speaker boost — вкл., Speed **0,95**.
4. Каждая строка ниже — **отдельный файл**. Текст вставлять как есть: числа уже написаны словами,
   «Мани Лайф» — так, как надо произнести.
5. Формат: MP3, 44,1 кГц, 64–96 кбит/с, моно. Длина каждой реплики — не больше 7–8 секунд.
6. Положить в репозиторий: `intro/ru/01.mp3 … 07.mp3`, `intro/ru/07r.mp3` (конец при пересмотре из «Настроек»),
   то же для `intro/uk/`. В `intro.js` вписать `AUDIO = { ru: 'intro/ru/', uk: 'intro/uk/', ext: '.mp3' }`.
   Вес: ~8 файлов × ~50 КБ на язык, грузятся только во время показа.

**Темп и манера.** Спокойно, тепло, без «рекламного» напора: как пилот, который коротко объясняет приборы.
Около 2,3 слова в секунду. Короткая пауза после первого предложения. Вопросы («Начнём?») — с лёгким подъёмом,
без восклицаний.

## Ограничения

- Имя «Джарвис» и голос актёра не использовать (права Marvel) — только голос Ориона.
- Ролик не даёт советов и не обещает доходность: только объясняет, как работает приложение.
- Если реплика вышла длиннее 8 секунд — слайд сам растянется под голос, но лучше перезаписать чуть быстрее.
