# Торговый отдел — устав

Создан 28.10.2026 по решению владельца: отдельная команда ИИ-трейдеров, чтобы команда приложения MoneyLife
занималась только приложением.

## Состав

| id | Имя | Роль |
|---|---|---|
| `trader-trend` | Олег | ИИ-трейдер: следование за трендом |
| `trader-mean` | Катя | ИИ-трейдер: возврат к среднему (торговля в диапазоне) |
| `risk` | Арсений | Риск-менеджер: лимиты, автостоп, право «нет» |
| `journal` | Майя | Журнал сделок и отчёты |

Рамки от компании: Рита (финансы) — бюджет и лимиты, Нина (правила) — разрешение владельца и правила бирж.

## Главное правило: сейчас только бумажная торговля

- **Бумажная (демо) торговля** — сделки «на бумаге» по настоящим ценам (CoinGecko), без денег, без биржи и без ключей.
  Стартовый бумажный счёт у каждого трейдера — $50.
- **Реальные деньги — только решение владельца** (его 5%: деньги, аккаунты, ключи). Порядок перехода, если владелец
  когда-нибудь решит: письменное разрешение с суммой, которую он готов потерять целиком (обсуждался потолок $50);
  отдельный счёт на бирже открывает сам владелец; ключ API — только на торговлю, **без права вывода**, вносит
  владелец сам, не в чат и не в код. До этого никто в компании счета не открывает и ключей не просит.
- Никаких советов владельцу или кому-либо, что покупать; никаких обещаний доходности. Большинство частных трейдеров
  и ботов проигрывают простому «купить и держать» — отдел обязан честно сравнивать себя с этим.

## Лимиты (действуют уже на бумаге — тренировка дисциплины)

1. Риск на одну сделку — не больше 2% счёта (на $50 — $1): стоп ставится до входа.
2. Убыток за день — не больше 5% счёта; за месяц — не больше 15%. Достигнут — автостоп: трейдер не торгует до конца периода.
3. Не больше 3 открытых сделок у трейдера; без плеча (маржи) и фьючерсов.
4. Комиссия в расчёте — 0,1% за вход и за выход (как у крупных бирж на споте).
5. Каждая сделка — с планом **до входа**: монета, вход, стоп, цель, причина. Без плана Арсений сделку не пропускает.

## Журнал и отчёты

- Журнал — `company/trading/journal.md` (ведёт Майя): дата, трейдер, монета, вход/стоп/цель, выход, итог в $ и %, комиссия.
- Раз в неделю — короткий итог, раз в месяц — отчёт: результат каждого трейдера против «просто держать BTC» за тот же
  период, худшая серия, соблюдение лимитов.
- Отдел работает в обычные смены компании, не чаще раза в сутки, и не тратит время команды приложения.
