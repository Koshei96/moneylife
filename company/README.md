# Отделы компании MoneyLife

Здесь лежат результаты неразработческих отделов. Всё — на русском, английские термины с переводом.

- `design/` — разборы экранов и предложения дизайнера.
- `marketing/` — тексты для Google Play (RU/UA), ключевые слова, план запуска, черновики постов и сценарии видео.
  Публикует только владелец.
- `finance/` — затраты, модель заработка, прогноз окупаемости.
- `research/` — конкуренты, требования Google Play, разборы идей.
